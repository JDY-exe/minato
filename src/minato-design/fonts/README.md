# Minato font sources

Source Sans 3 (normal/italic), Hina Mincho (regular), Noto Sans JP (normal), Google Sans Code (normal/italic), and Newsreader (regular/italic, weight 400, optical sizes 6–72) are self-hosted WOFF2 assets from the Google Fonts CSS API, fetched 2026-11-24. Each family’s SIL Open Font License is included alongside these files, from `https://github.com/google/fonts/tree/main/ofl/`.

Assets retain Google Fonts' Unicode subsets. Browsers request the subsets required by the text on a page. Latin families include Latin and Latin extended; Japanese families retain their full supplied coverage. Shared variable-font files are reused across 400, 500, and 700.


Japanese italic variants intentionally stay upright, per the product decision. No synthetic bold or italics are used. Google Sans Code falls back to Noto Sans JP for Japanese glyphs, which are not guaranteed to share its monospace metrics.
