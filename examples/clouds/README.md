# First cloud draft

`seed-7/cloud.blend` is the first editable scene, generated with Blender 5.3. `seed-7/frame-0001.png` is its first actual Cycles render (640×400, transparent RGBA, 24 samples). No full animation is included. This is a rough procedural shape study, not a finished realistic cloud.

The snapshot was generated on macOS; its render output and GPU settings may need changing on another machine. Prefer `npm run clouds:scene -- --seed 7` to regenerate for your machine. Read `HANDOFF.md` at the repository root before continuing.
